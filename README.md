# EARTH / 001 — A Living Planet

A cinematic, interactive 3D Earth experience built with Three.js.

## Features
- Realistic Earth textures, normal/specular maps, cloud layer and atmospheric rim
- Animated starfield and automatic rotation
- Drag to rotate, scroll/pinch to zoom, and camera controls
- Location search for selected cities and countries
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a modern browser with an internet connection. Three.js and planetary textures load from public CDNs.

## Deploy
GitHub Actions deploys the site to GitHub Pages on every push to `main`. In repository Settings → Pages, ensure the source is set to **GitHub Actions** if GitHub has not enabled it automatically.
